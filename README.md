## 🚀 Como Executar o Projeto Localmente

Este repositório contém a página web de portfólio pessoal construída com HTML5, CSS3 moderno e JavaScript.

1. Clone este repositório:
   ```bash
   git clone https://github.com/TonyMPCastro/site.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd site
   ```
3. Abra o arquivo `index.html` em seu navegador de preferência ou execute com a extensão **Live Server** no VS Code.
